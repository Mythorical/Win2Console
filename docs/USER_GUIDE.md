# User guide

Win2Console looks and works like the Xbox Series X|S dashboard. Everything works with any controller,
and keyboard and mouse work too. Screenshots are in [`docs/screenshots/`](screenshots/).

## Controls
| Controller | Keyboard | What it does |
|---|---|---|
| D-pad / left stick | Arrow keys | Move |
| A | Enter / Space | Select / play |
| B | Esc / Backspace | Back |
| X | X | Pin or unpin the focused game |
| Y | Y | Search (on Home), Sort (in My games & apps) |
| ≡ Menu | M | More options for the focused game |
| ⧉ View | V | Customize (Home), Add a game (My games & apps) |
| LB / RB | PageUp / PageDown | Switch Guide tabs; RB on Home opens My games & apps |
| Guide (Xbox / PS button) | Home | Open or close the Guide |

## Who's playing?
At startup, pick your profile. Choose **Add new** to create one: name it with the on-screen keyboard,
then pick a colour and a profile picture. Each profile has its own playtime, pins, colour and background.

![Profile picker](screenshots/m1-profile-picker.png)

## Home
- The big tile is the game you played last. Press **A** to play it.
- The coloured squares are your first pins plus shortcuts: Settings, Add a game, Search, Switch profile, Power.
- **My games & apps** opens your full library. The wide tiles next to it are your other recent games.
- Press **Down** past the bottom row to reach the sections: Pinned, Steam, Epic Games, Custom.

![Home](screenshots/m1-home.png) ![Home section](screenshots/m1-home-section.png)

## The Guide
Press the **Guide** button anywhere. It has Home, My games & apps, your recent games and Settings, and the bottom
row has Search, Add a game, Switch profile and Power. Use **LB/RB** to switch to the profile tab.

![Guide](screenshots/m1-guide.png)

## My games & apps
The sidebar filters by launcher (All games, Steam, Epic Games, Custom), and **Hidden** lists games you've hidden.
Move right into the grid; the sidebar slides away. **Y** changes the sort order, and **≡** opens a game's options:
Play, Pin to Home, Change cover art, Change background art, Hide, Remove (custom games).

![Sidebar](screenshots/m1-library-sidebar.png) ![Grid](screenshots/m1-library-grid.png)

## Adding a game that isn't in a launcher
Choose **Add a game** (on Home, in the Guide, or in My games & apps), browse to the game's `.exe` with the
controller file browser, name it, and optionally choose cover art. Steam and Epic games are found
automatically, and Steam's own box art is used when Steam has it cached.

## Search
Press **Y** on Home. Type with the on-screen keyboard (or a real keyboard). Results update as you type.
Press **Up** from the top row of the keyboard to reach the results.

![Search](screenshots/m1-search.png)

## On-screen keyboard
Laid out like the Xbox keyboard. **X** = backspace, **Y** = space, **LB/RB** move the cursor, **≡** = done,
**B** = cancel. The first letter is capitalised automatically.

![Keyboard](screenshots/m1-keyboard.png)

## Settings
| Category | Options |
|---|---|
| Profile | Profile name, Profile picture, My color, My background (default wallpaper, solid colour, or your own image), Switch profile, Delete this profile |
| Library | Show hidden games, Rescan library, Add a game |
| System | Start with Windows, About, Exit to desktop |
| Power | Sleep, Restart, Shut down, Exit to desktop |

![Settings](screenshots/m1-settings-profile.png)

## Playtime
Win2Console notices when a game starts and stops, and records playtime for the signed-in profile.
When the game closes, Win2Console comes back to the front.
